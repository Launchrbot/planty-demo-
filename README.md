# Planty 🌿

Watering reminders for your plants. Local-first: your plant list lives in your
browser (localStorage), no accounts, no server.

## Use it
Open `index.html` in a browser. Add a plant and how often it drinks; Planty
shows when each one is next due.

## Files
- `index.html` — the page
- `app.js` — plant list + rendering
- `utils.js` — date helpers
- `config.js` — app config
- `style.css` — styles
